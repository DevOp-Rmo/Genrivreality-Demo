Genrivreality — Ready-to-Upload Website Package
================================================

Included Files:
- index.html          : Main responsive HTML5 structure
- styles.css          : Custom glassmorphism, animations & scrollbar styles
- script.js           : All interactive UI/UX logic, 12 portal tabs, forms & calculators
- images/hero.jpg     : Hero skyline background image
- images/prop1.jpg    : Mumbai Worli Penthouse image
- images/prop2.jpg    : Bengaluru Whitefield Biophilic Villa image
- images/prop3.jpg    : Gurugram Golf Course Road Residences image

- images/prop5.jpg    : Kolkata New Town Sky-Forest Towers image
- images/prop6.jpg    : Pune Koregaon Park Studio & Co-Living image

How to Deploy / Run:
1. Extract this ZIP folder anywhere on your computer or upload all files directly to your web hosting root (cPanel, Netlify, Vercel, GitHub Pages, Hostinger, AWS S3, etc.).
2. Keep the `images/` folder in the same directory as `index.html`, `styles.css`, and `script.js`.
3. Open `index.html` in any browser — everything works out of the box!
